## Coursework

This coursework for CS402.3 is worth 20% of the module marks and contains two parts: Prototype and a report. The prototype is basically a working software with backend coding. The report should contain screenshots, testing results, discussion, and most importantly individual contribution.

### Scenario

You are asked to create a student attendance management system based on the signing sheets. The signing sheets have a specific layout which is static. Students can sign the sheet at a given space using different color pens.

- The admin staff would take snapshots using their smart phones of these signing sheets and provide you the image files.
- They also provide you a text file containing the student indices and subject related information.
- Once you receive those files, your program should process the image and text content and identify whether a student is present or absent based on the appearance of a signature.

The main focus is with two key technologies:

- Image processing
- Data visualization

### The Big Picture

Suppose the student signatures are in tabular format like the table below where students sign using different color pens.

| #   | Student Index | Name       | Signature      |
| --- | ------------- | ---------- | -------------- |
| 1   | 001           | John Snow  | JSnow          |
| 2   | 007           | James Bond | JamesBond007   |
| 3   | 009           | Andare     |                |
| …   | …             |            |                |

### Processing

Your program preferably written in Python language should take the above sheet as an input and identify who was present and who was absent, i.e. Andre was absent.

```
$ python sams.py 10.07.2019.png info.xml
```

While the program is running you need to show the progress of the image processing. Such as greyscale, binarization, etc. Once the image processing is completed you need to use the info.xml like as shown in Figure 1 and map the processed data and store the attendance in a local DB.

> *Figure 1. info.xml where the students' records kept*

### Visualization

The second program should show a summary of attendance for a given student. You are required to display the information using a suitable graph. Use the knowledge gain in data visualization techniques.

```
$ python infovis.py 001
```

### Recognition

An attempt to distinguish the student signatures using any advanced library or self-created would result higher grades. You must collect signatures of the given student, compare, and report if they are not matching.

```
$ python investigate.py 001
```

### Grouping

You are required to form groups of ten members each playing different role in the project, but everybody is contributed to the main concerns: image processing and visualization. The report should contain individual contribution of each about two pages including technologies and coding.

## Deliverables

### Prototype

The prototype should be a working solution where one can input different images and get a summary of attendance.

### Report

The report should contain screenshots of the image processing steps, testing results for the given input images (all five signing sheets found in 'CGV Signing Sheets.zip'), discussion about challenges faced, and individual contribution. The front page should contain group member names, roles, indices, subject title, and code.

Each member must explain his/her contribution with a minimum of two pages; one can use illustrations for explanations, then paragraphs need to be extended.

You are also required to prepare the report using standard references, figures, tables, and equations.
